🎯 Objetivo do projeto

Este projeto tem como objetivo:

Praticar lógica de programação

Trabalhar com eventos e manipulação do DOM

Entender o funcionamento de um CRUD no front-end

Aplicar boas práticas iniciais de organização de código

Utilizar Git e GitHub no fluxo de desenvolvimento

🚀 Possíveis melhorias futuras

Armazenamento das tarefas no localStorage

Validação de campos

Filtro de tarefas (concluídas / pendentes)

Melhorias de acessibilidade

Versão com framework (React, por exemplo)
